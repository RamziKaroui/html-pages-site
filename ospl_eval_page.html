Preliminary Installation Instructions

After downloading the selected package, install the software, save the license file into <OpenspliceDDS_installation_diretory>/etc, then run release.com on Linux or release.bat on Windows from <OpenspliceDDS_installation_diretory> to prepare the environment. Use the supplied documentation and the Roundtrip and Throughput examples to validate the installation.
