Class: TypeSupport

OpenspliceDDS.TypeSupport()

The description of an IDL type, used in Topic creation.

Instances are not directed created by users. Rather, they are obtained by calling importIDL() and passed to Participant.createTopic() are part of the DDS topic creation/registration process.
